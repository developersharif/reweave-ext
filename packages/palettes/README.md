# @reskin/palettes

Palettes bundled with the extension (template-schema §6). A palette is colours only: it re-themes any template that consumes `standard/v1`, and through the adapter's theme map (D-033) the site itself.

| Palette | Colours from | Licence |
|---|---|---|
| Default Dark | this project (the `standard/v1` defaults) | MIT |
| Default Light | this project | MIT |
| Catppuccin Mocha | [Catppuccin palette](https://github.com/catppuccin/palette), "Mocha" flavour | MIT, [`licenses/catppuccin.txt`](licenses/catppuccin.txt) |
| Nord | [Nord](https://github.com/nordtheme/nord), `src/nord.css` | MIT, [`licenses/nord.txt`](licenses/nord.txt) |

Upstream colours were copied from the repositories above on 2026-11-19. These are community palettes we bundle; they are not official ports.
